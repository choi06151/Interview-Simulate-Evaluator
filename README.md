# 게임 엔진 클라이언트 프로그래머 면접 평가기

게임 엔진 클라이언트 프로그래머 모의 면접을 질문별 텍스트 평가와 별도 음성 전달 평가로 기록하는 평가 기준 및 도구 모음입니다.

## 평가 기준

텍스트 답변과 말하기 전달력은 서로 섞지 않고 따로 평가합니다. 각 회차에는 질문별 근거, 피드백, 텍스트 점수, 음성 점수, 두 점수의 평균 총점을 기록합니다.

### 텍스트 평가 — 질문별 100점

실제 면접에서 질문한 주제를 평가 단위로 삼습니다. 같은 주제의 후속 질문은 한 단위로 묶고, 독립된 주제는 별도 질문으로 채점합니다. 질문별 점수는 다음을 기준으로 부여합니다.

- **정확성:** 핵심 개념·원리·용어가 맞는가
- **직접성:** 질문의 요구에 바로 답했는가
- **근거와 구체성:** 사례, 코드 흐름, 본인의 역할이나 판단을 설명했는가
- **깊이와 적용:** 적용 조건, 트레이드오프, 검증 방법을 이해하는가
- **행동 질문:** 상황, 본인의 행동, 판단 이유, 결과와 회고가 구체적인가

| 점수 | 기준 |
|---:|---|
| 0 | 답변하지 않았거나 핵심 결론이 틀려 질문에 답하지 못함 |
| 1–20 | 관련 용어만 제시하거나 매우 피상적이며 핵심 근거나 원리가 없음 |
| 21–40 | 일부는 맞지만 핵심 메커니즘·경험·판단 근거에 큰 공백이 있음 |
| 41–60 | 질문의 핵심에는 답했으나 정확성·깊이·사례·검증 중 중요한 부분이 빠짐 |
| 61–80 | 정확하고 구조적으로 설명하며 적절한 사례·이유·검증을 제시함 |
| 81–100 | 깊이 있는 추론과 구체적 근거, 대안·경계 조건·검증·회고가 일관됨. 드물게 부여 |

질문별 점수를 단순 평균해 **텍스트 점수 / 100**을 계산합니다. 질문하지 않은 주제는 감점하지 않고 평가 범위 밖으로 기록합니다. 질문 난이도, 힌트, 답변 기회와 평가 범위를 함께 남깁니다.

### 음성 전달 평가 — 100점

텍스트의 기술 정답률이나 경험 성과를 다시 채점하지 않고, 말로 답변을 전달하는 방식만 평가합니다.

| 항목 | 배점 | 관찰 기준 |
|---|---:|---|
| 이해 가능성 | 40 | 발화가 실제로 알아들을 수 있는지, 핵심 표현이 반복적으로 뭉개지거나 가려지는지 |
| 구두 답변 구조 | 30 | 요점·설명·예시·결론을 청자가 따라갈 수 있게 연결하는지 |
| 질문 대응과 대화 흐름 | 20 | 질문의 초점과 후속 질문에 맞게 답하고, 필요하면 확인·정정하는지 |
| 전달 조절 | 10 | 속도와 멈춤이 의미 전달을 방해하는지. 빠르거나 느리다는 인상만으로 감점하지 않음 |

직접 음향을 검토한 평가와 로컬 ASR·시간 정보 기반 **잠정 평가**를 구분해 표시합니다. ASR 인식률은 명료도 점수가 아니며, 화자 분리되지 않은 녹음의 속도·휴지를 후보자 개인의 특성으로 단정하지 않습니다. 직접 청취하지 못한 경우 잠정 점수와 낮은 신뢰도를 명시하고, 근거가 없는 항목은 평가 불가로 남깁니다.

억양, 방언, 음색, 목소리의 높낮이, 성별·나이, 자신감이나 호감도 인상은 평가하지 않습니다. 말더듬이나 비유창성도 그 자체로 감점하지 않고 실제 의미 전달을 막은 구간이 확인될 때만 반영합니다. 협업·인성 질문은 성격을 진단하지 않고 구체적인 행동과 판단 근거를 평가합니다.

### 최종 점수와 비교

텍스트와 음성 점수가 모두 있으면 두 점수의 산술 평균을 정수 반올림해 **최종 총점 / 100**으로 기록합니다. 음성 근거가 없으면 음성 점수와 최종 총점을 산출 보류합니다. 총점만으로 채용 합격 여부를 판정하지 않으며, 질문 범위·난이도가 다른 회차의 점수 차이를 성장이나 퇴보로 단정하지 않습니다.

세부 기준과 기록 형식은 [`references/scoring-rubric.md`](references/scoring-rubric.md), [`references/voice-scoring-rubric.md`](references/voice-scoring-rubric.md), [`references/output-format.md`](references/output-format.md)에 있습니다.

## 구성

- `SKILL.md`: 면접 평가 AI의 역할과 일관된 평가 절차
- `references/`: 텍스트·음성 루브릭, 회차 기록 스키마, 결과 형식, 음성 분석 안내
- `question-library/`: 공통 면접 질문 모음
- `records/`: 참가자별 회차 원문, 평가, 총점 및 개인별 추천 질문
- `scripts/analyze_voice.py`: MP3/WAV 로컬 음성 인식 및 시간 정보 추출

## 음성 분석

```powershell
python -m pip install -r requirements-audio.txt
python scripts/analyze_voice.py "path\to\interview.mp3" --language ko --model small
```

전사와 시간 정보는 로컬에서 추출합니다. 음성 분석 결과만으로 발음, 음색, 감정, 억양을 판정하지 않습니다. 직접 청취하지 못한 평가는 잠정 점수와 낮은 신뢰도를 명시합니다. 자세한 평가 기준과 제한은 `references/voice-scoring-rubric.md` 및 `references/audio-analysis-workflow.md`를 참고하세요.

## 기록 데이터

`records/participants/`에는 면접 참여자의 실명, 전사, 평가 결과 및 일부 음성 녹음이 포함되어 있습니다. 이 저장소는 공개 상태이므로 기록 파일을 누구나 열람하고 내려받을 수 있습니다.
