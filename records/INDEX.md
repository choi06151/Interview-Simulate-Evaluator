# 모의 면접 기록 보관소

참가자별로 회차를 누적 보관합니다. 각 회차 폴더에는 대화 전문과 그 대화에 대한 평가를 각각 저장합니다.

## 참가자

| 참가자 ID | 표시 이름 | 회차 기록 |
|---|---|---|
| P01 | 최재원 | [세션 폴더](participants/P01/sessions/) |
| P02 | 김호준 | [세션 폴더](participants/P02/sessions/) |
| P03 | 뮨규 (세 번째 참가자) | [세션 폴더](participants/P03/sessions/) |

사람별 추천 질문은 각 참가자의 `question-recommendations/` 폴더에 누적합니다. 공통 후보 문항은 [질문 라이브러리](../question-library/question-library.md)에 있습니다.

실제 이름과 참가자 ID의 연결은 사용자가 알려준 뒤 갱신합니다. 이름이 확정되기 전에는 기록을 임의로 연결하지 않습니다.

## 회차 폴더 규칙

`participants/<참가자 ID>/sessions/<세션 ID>/`

예시: `participants/P01/sessions/P01-2026-10-19-01/`

- `transcript.md`: 면접 대화 전문. 받은 내용을 가능한 한 그대로 보존합니다.
- `evaluation.md`: 텍스트 질문별 점수와 텍스트 점수(/100), 제공된 녹음의 음성 전달 점수(/100), 두 점수가 모두 있을 때의 평균 최종 총점(/100), 피드백과 성장 비교.
- `question-recommendations/`: 해당 참가자에게 다음 회차에 추천할 질문을 회차별 파일로 누적합니다. 평가된 약점과 질문 이력에 맞춰 작성합니다.

새 회차는 새 폴더에 추가합니다. 이미 저장된 회차는 새 기록으로 조용히 덮어쓰지 않습니다. 정정이 필요하면 변경 사유와 날짜를 평가 파일에 남기고 원문은 보존합니다.

## 대화 입력 시 처리

1. 참가자 ID와 회차를 확인합니다. 참가자 식별이 불명확하면 저장 위치를 추정하지 않습니다.
2. 고유 세션 ID를 지정합니다. 날짜와 해당 참가자의 당일 회차 번호를 조합하는 것을 권장합니다.
3. 대화 전문을 `transcript.md`에 저장하고, 전문 기준으로 평가한 결과를 `evaluation.md`에 저장합니다.
4. 두 파일의 세션 ID와 참가자 ID가 같은지, 텍스트 점수가 채점된 질문 점수의 평균과 일치하는지 확인합니다. 음성을 평가했다면 네 항목의 합이 음성 점수와 같은지, 최종 총점이 텍스트 점수와 음성 점수의 평균(정수 반올림)인지 확인합니다.
5. 성장 분석은 동일 참가자의 이전 기록만 사용합니다.

## 새 기록 템플릿

신규 세션 폴더를 만들 때 `templates/transcript-template.md`와 `templates/evaluation-template.md`를 복사해 사용합니다. 템플릿 표식은 실제 내용으로 채운 뒤 저장합니다.

사람별 질문 추천은 참가자 폴더의 `question-recommendations/`에 회차별 파일로 추가합니다. 첫 평가 전에는 개인화 질문을 임의로 채우지 않습니다. 공통 질문 후보는 [질문 라이브러리](../question-library/question-library.md)를 참고합니다.
