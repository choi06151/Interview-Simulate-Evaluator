2. **Q2 C# 이벤트 종류:** Action은 delegate 타입의 일반 멤버/변수로 호출 제어가 넓고, `event`는 delegate를 외부에 노출하되 구독자는 `+=`/`-=`만 할 수 있으며 발행 측만 호출하게 제한합니다. UnityEvent는 Inspector 연결과 직렬화가 가능한 Unity 이벤트라는 점을 비교하고, `OnEnable` 구독·`OnDisable` 해제 사례를 코드로 연습합니다.
3. **Q4 FSM/HFSM:** FSM, State 패턴, HFSM을 구분해 설명합니다. HFSM 예로 `Grounded` 상위 상태 아래 `Idle`/`Run`, `Airborne` 아래 `Jump`/`Fall`을 두고, 상위 상태의 공통 전이/동작을 어떻게 재사용하는지 설명합니다.

## 기술적으로 정확히 짚을 부분

- Flyweight는 여러 객체가 공유할 수 있는 intrinsic state와 각 객체별 extrinsic state를 분리해 중복 상태 저장을 줄입니다. Object Pooling은 객체 인스턴스를 재사용하는 기법이며 서로 결합해 사용할 수 있지만 목적은 다릅니다.
- C# `event`는 delegate 기반 멤버이며, 선언한 타입 외부에서는 구독/해제만 가능하고 발행 호출은 할 수 없습니다. UnityEvent는 Inspector에서 연결할 수 있고 Unity 직렬화 대상이 되는 이벤트 형식입니다.
- FSM은 유한한 상태와 전이를 모델링합니다. State 패턴은 상태별 동작을 별도 객체로 분리하는 구현 선택지이며 모든 FSM이 State 패턴으로 구현되는 것은 아닙니다. HFSM은 상태를 계층적으로 중첩해 상위 상태의 동작·전이를 하위 상태가 공유하도록 구성합니다.
