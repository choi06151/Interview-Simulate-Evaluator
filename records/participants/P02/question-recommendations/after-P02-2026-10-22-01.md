# 김호준 4회차 이후 개인별 추천 질문

- 참가자: 김호준 (P02)
- 기준 세션: [P02-2026-10-22-01](../sessions/P02-2026-10-22-01/evaluation.md)
- 기준 루브릭: 텍스트 v2.0
- 목적: 이번 면접에서 답변하지 못했거나 개념 경계가 불명확했던 기초 질문을 재검증

## 1. 프로세스와 스레드

- 연결 평가: Q1 — 차이 설명 (0/100)
- 난이도: 기초
- 질문: 게임을 실행했을 때 프로세스가 보유하는 자원과 스레드가 담당하는 일을 설명하고, 한 프로세스에서 두 스레드가 공유하는 것과 각각 별도로 가지는 것을 구분해 주세요.
- 후속 질문:
  - 메인 스레드와 렌더링/작업 스레드는 어떤 종류의 일을 맡을 수 있나요?
  - 두 스레드가 같은 인벤토리를 동시에 수정하면 어떤 문제가 생길 수 있나요?
- 좋은 답변 신호: 프로세스 주소 공간/자원과 스레드 실행 흐름/스택·레지스터 상태를 구분함.

## 2. BFS와 DFS, 큐와 스택

- 연결 평가: Q4 — BFS 자료구조 답변 미완료 (0/100)
- 난이도: 기초
- 질문: 격자 맵의 시작점에서 목표까지 탐색할 때 BFS와 DFS가 다음에 방문할 칸을 고르는 순서를 설명하고, 각각 큐/스택 중 어떤 자료구조를 쓰는지 작은 맵으로 추적해 주세요.
- 후속 질문:
  - 간선 비용이 모두 같을 때 BFS가 최단 경로를 찾는 이유는 무엇인가요?
  - DFS는 어떤 상황에서 메모리/탐색 특성이 유리할 수 있나요?
- 좋은 답변 신호: BFS는 FIFO 큐로 가까운 깊이부터, DFS는 LIFO 스택/재귀로 깊이 우선 탐색함을 진행 순서와 함께 설명함.

## 3. 비동기와 Unity 코루틴

- 연결 평가: Q5 — 비동기 개념 (25/100)
- 난이도: 중
- 질문: 비동기 작업이 호출 스레드를 언제 멈추게 하고 언제 양보하는지 설명하고, Unity 코루틴과 Task/스레드 작업의 차이를 예로 들어 주세요.
- 후속 질문:
  - `yield return new WaitForSeconds`를 사용하면 코드가 병렬 스레드에서 도나요?
  - 파일 다운로드 대기와 큰 경로 탐색 계산은 각각 어떻게 처리하겠습니까?
- 좋은 답변 신호: 비동기 완료 대기, 프레임 양보, CPU 병렬 실행을 각각 구분하고 메인 스레드 안전성을 고려함.

## 4. Observer와 Mediator 비교

- 연결 평가: Q8 — 패턴 차이 답변 미완료 (25/100)
- 난이도: 중
- 질문: 체력 변경을 UI와 사운드가 구독해 통지받는 구조와, 여러 UI 패널의 상호작용을 한 조정자가 처리하는 구조를 각각 설계해 Observer/Mediator의 차이를 설명해 주세요.
- 후속 질문:
  - 각 패턴에서 누가 누구를 알고 있나요?
  - Observer 구독 해제와 Mediator에 모든 로직이 몰리는 문제는 어떻게 관리할 수 있을까요?
- 좋은 답변 신호: 일대다 여부가 아니라 이벤트 통지 관계와 동료 간 상호작용 중재 책임으로 구분함.

## 5. Object Pool의 자원 trade-off

- 연결 평가: Q7 — 풀링 목적 설명 (75/100)
- 난이도: 중
- 질문: 총알 오브젝트 풀을 구현한다고 할 때 초기 풀 크기, 풀 고갈 시 확장/폐기 정책, 반환 시 초기화할 상태를 어떻게 정하겠습니까?
- 후속 질문:
  - 풀이 지나치게 크면 어떤 비용이 발생하나요?
  - 비활성 오브젝트가 이벤트 구독이나 코루틴을 유지하면 어떤 버그가 생길 수 있나요?
- 좋은 답변 신호: 생성 비용 감소뿐 아니라 메모리 상한, 재초기화 누락, 활성 상태와 구독/코루틴 정리를 함께 고려함.
