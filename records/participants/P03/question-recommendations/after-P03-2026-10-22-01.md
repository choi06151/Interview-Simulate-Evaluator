# 김문규 4회차 이후 개인별 추천 질문

- 참가자: 김문규 (P03)
- 기준 세션: [P03-2026-10-22-01](../sessions/P03-2026-10-22-01/evaluation.md)
- 기준 루브릭: 텍스트 v2.0
- 목적: 페이지 폴트 처리, 스케줄링 선택, 팩토리 설계, 재귀 종료 메커니즘을 재검증

## 1. 페이지 폴트 처리와 가상 주소

- 연결 평가: Q1 — 가상 메모리/페이지 폴트 (25/100)
- 난이도: 중
- 질문: 프로세스가 접근한 가상 페이지가 페이지 테이블상 유효하지만 현재 RAM에 없을 때 페이지 폴트가 발생한 뒤 어떤 일이 순서대로 일어나는지 설명해 주세요.
- 후속 질문:
  - 주소 자체가 잘못된 경우와 유효 페이지가 물리 메모리에 없는 경우는 어떻게 다른가요?
  - soft fault와 hard fault의 차이는 무엇인가요?
  - 게임에서 페이지 폴트가 자주 발생하면 로딩/프레임 시간에 어떤 영향을 줄 수 있나요?
- 좋은 답변 신호: 유효성 확인, 페이지 위치 탐색, 필요 시 backing store에서 적재, 페이지 테이블 갱신, faulting 명령 재개를 설명하고 디스크 접근이 항상 필요한 것은 아님을 구분함.

## 2. 인터랙티브 작업의 CPU 스케줄링

- 연결 평가: Q2 — 스케줄링 알고리즘과 응답성 (25/100)
- 난이도: 중
- 질문: FCFS, SJF/SRTF, Round Robin이 다음 실행 대상을 고르는 기준을 설명하고 각각의 응답성·공정성 trade-off를 비교해 주세요.
- 후속 질문:
  - SJF는 왜 “가장 최근에 들어온 작업 우선”이 아닌가요?
  - time quantum을 지나치게 크게/작게 두면 어떤 문제가 생길까요?
  - 인터랙티브 입력 처리에서 평균 대기 시간과 첫 응답 시간 중 어떤 목표가 더 중요한 상황이 있을까요?
- 좋은 답변 신호: 알고리즘 정의를 혼동하지 않고, 응답성과 처리량/문맥 전환 비용의 균형을 근거와 함께 설명함.

## 3. 게임 오브젝트 스폰용 Factory

- 연결 평가: Q3 — Factory 패턴 설명과 장단점 (45/100)
- 난이도: 중
- 질문: 적 종류별로 다른 초기화 데이터와 컴포넌트를 가진 적을 스폰하는 간단한 Unity 구조를 예로 들어, Factory가 호출부와 구체 생성 클래스를 어떻게 분리하는지 설명해 주세요.
- 후속 질문:
  - 새 적 타입 추가 시 어떤 파일/등록부를 수정해야 하나요?
  - 적 종류가 하나뿐이고 초기화도 단순하다면 Factory를 만들지 않는 편이 나을까요?
  - Factory와 Object Pool은 생성/재사용 관점에서 어떻게 다른가요?
- 좋은 답변 신호: 단순히 “여러 객체를 만든다”를 넘어 생성 책임과 의존성 경계를 설명하고 불필요한 추상화 비용도 고려함.

## 4. 재귀 종료와 스택 깊이

- 연결 평가: Q4 — 기저 조건과 StackOverflow (20/100)
- 난이도: 중
- 질문: 리스트를 재귀로 순회하는 함수를 예로 들어 기저 조건과 재귀 단계가 각각 무엇인지 말하고, 입력 크기가 커질 때 호출 스택이 어떻게 변하는지 추적해 주세요.
- 후속 질문:
  - 기저 조건이 없으면 어떤 일이 발생할까요?
  - 깊은 재귀를 반복문이나 명시적 스택으로 바꾸면 어떤 trade-off가 있나요?
  - 게임 클라이언트에서 재귀 깊이가 과도한 경우 어떤 입력/레벨 데이터를 점검하겠습니까?
- 좋은 답변 신호: 기저 조건이 종료를 보장하고, 각 호출 프레임이 반환까지 스택에 남아 무한/과도한 중첩 시 스택 공간을 소진한다는 인과를 설명함.
