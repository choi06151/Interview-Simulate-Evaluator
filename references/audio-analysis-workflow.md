# 음성 분석 도구 사용법

`scripts/analyze_voice.py`는 MP3/WAV 등 녹음에서 로컬 음성 인식 결과, 발화 구간, 단어 시각, 인식 확률, 휴지 구간과 대략적인 발화 속도를 JSON으로 추출합니다. 음성 파일과 전사 데이터는 외부 서비스로 보내지 않습니다. `faster-whisper` 모델이 이 기기에 없으면 첫 실행 때 Hugging Face에서 모델을 내려받습니다.

## 실행

프로젝트 루트에서 다음을 실행합니다.

```powershell
python -m pip install -r requirements-audio.txt
python scripts/analyze_voice.py "C:\path\to\interview.mp3" --language ko --model small
```

`--language auto`로 언어 감지를 요청하거나 `--output`으로 JSON 저장 위치를 지정할 수 있습니다. 기본 출력은 입력 파일 옆의 `<파일명>.voice-evidence.json`입니다.

## 평가에서 사용

1. JSON의 구간별 전사와 시각을 제공된 TXT와 대조하고, 후보자 발화와 면접관 발화를 구별합니다. ASR이 화자를 자동으로 구분하지는 않습니다.
2. 인식 확률과 전사 불일치는 알아듣기 쉬움의 참고 신호일 뿐 단독 점수로 변환하지 않습니다. 이름·전문용어·소음·모델 오류가 신호를 왜곡할 수 있습니다.
3. 휴지와 속도는 전달 조절을 검토할 근거로만 사용합니다. 빠르거나 느리다는 이유만으로 감점하지 말고 실제로 의미 전달을 방해하는지 확인합니다.
4. 구두 답변의 구조와 질문 대응은 ASR 전사를 통해 요점 순서와 후속 질문 반응을 평가하되, 기술 정답률·경험의 성과는 텍스트 점수에서만 평가합니다.
5. ASR 전사 및 타임스탬프는 원본 음성을 대체하지 않습니다. 직접 청취가 가능하면 원본 청취를 우선해 채점하고, 직접 청취가 불가능하면 ASR/시간 분석 근거만으로 `잠정 음성 점수(저신뢰도)`를 낼 수 있습니다. 이때 명료도는 후보자 발화 구간의 전사 누락·불일치와 TXT 대조를 제한적으로 사용하며 ASR 오류 가능성을 명시합니다. 답변 구조와 질문 대응은 구간별 전사로 판단하고, 속도·멈춤은 화자 분리가 확인된 구간에서만 판단합니다. 화자 분리가 되지 않으면 혼합 화자 지표를 후보자 점수로 단정하지 말고 해당 하위 항목을 평가 불가 처리하거나 신뢰도를 낮춥니다. 억양·음색·감정·음량을 자동 전사로 추론하지 않습니다.
6. 음성 점수에 잠정/저신뢰도 표기를 붙이고, 직접 청취 여부와 분석 도구·모델·한계를 기록합니다. 텍스트 점수와 잠정 음성 점수가 모두 있을 때만 평균 최종 총점을 계산하며, 최종 총점도 같은 저신뢰도 한계를 함께 표시합니다.

음성 전달력 항목·배점·공정성 경계는 [음성 평가 루브릭](voice-scoring-rubric.md)을 따릅니다. 분석 JSON은 보조 근거이며, 질문별 텍스트 점수와 음성 점수를 섞지 않습니다.
