# 텍스트·음성 이중 평가 결과 출력 형식

매회 아래 구조를 유지한다. 면접에서 나온 평가 질문을 각각 채점하고, 역량별 총점 표는 만들지 않는다.

## 1. 세션 정보

- 참가자 ID / 표시 이름:
- 세션 ID / 날짜:
- 포지션 및 레벨:
- 면접 유형:
- 분석한 대화 범위:
- 루브릭 버전: 텍스트 v2.0 / 음성 v2.0
- 평가 자료: 대화 전문 / 음성 녹음 / 둘 다 (해당 항목)
- 평가된 질문 수:
- 평가 범위 및 신뢰도: 높음 / 보통 / 낮음 — 기술·행동 질문 범위와 한 문장 근거

## 2. 질문별 점수

**텍스트 점수: NN / 100** (채점 가능 질문 점수의 단순 평균, 정수 반올림)

**음성 점수: NN / 100** (녹음이 제공된 경우만; 없거나 분석 불가하면 `미평가`)

**최종 총점: NN / 100** ((텍스트 점수 + 음성 점수) ÷ 2; 두 점수가 모두 있을 때만 산출)

텍스트 점수는 아래 채점 가능한 질문 점수의 단순 평균이며 정수로 반올림한다. 질문별 배점 합계 방식은 쓰지 않는다.

| 질문 | 역량 태그 | 답변 점수 | 평가 근거 및 개선점 |
|---|---|---:|---|
| Q1. 질문 요지 | 태그 | NN/100 | 짧은 근거 발췌/발화 위치 → 무엇이 입증됐고 무엇이 빠졌는지 |
| Q2. 질문 요지 | 태그 | NN/100 |  |

질문한 내용에 답하지 않았거나 답변을 넘긴 경우 0점으로 기록한다. 면접에서 전혀 묻지 않은 영역은 점수 표에 넣지 않고 아래 `평가하지 못한 영역`에 적는다. 같은 주제의 후속 질문은 한 질문 단위로 묶어 점수와 근거에 반영한다.

### 평가하지 못한 영역

질문이 없었던 직무 역량을 나열한다. `평가 기회 부족`을 후보자 감점 사유로 쓰지 않는다.

## 3. 음성 전달 점수

녹음이 제공되면 아래 항목별 점수와 짧은 근거 또는 시각을 기록한다. 녹음이 없으면 `음성 자료 미제공 — 음성 점수 및 최종 총점 미산출`로 표시한다.

| 항목 | 점수 | 관찰 근거 및 개선점 |
|---|---:|---|
| 이해 가능성 (30점) | NN/30 | 실제 청취 및 후보자 구간 전사 근거 |
| 말하기 속도와 안정성 (20점) | NN/20 | 후보자 단독 속도·구간별 변화와 전달 영향 |
| 호흡·쉼·비유창성 (20점) | NN/20 | 후보자 내부 쉼, 실제로 전달을 방해한 끊김. 쉼을 호흡 횟수로 간주하지 않음 |
| 음량과 신호 안정성 (15점) | NN/15 | 청취 가능성 및 신호 변화. 장비·환경 결함은 후보자 감점에서 제외 |
| 억양·강세·운율 (15점) | NN/15 | 문장 경계와 강조가 전달에 준 영향. 음색이나 억양 취향은 평가하지 않음 |

**음성 점수: NN / 100** — 측정 지표는 자동 점수가 아니라 검토 근거다. 후보자 화자를 신뢰성 있게 분리하지 못하면 점수와 최종 총점을 보류한다. 세부 경계는 [음성 평가 루브릭](voice-scoring-rubric.md)을 따른다.

### 음성 평가 리뷰

점수표와 별도로 음성 전달의 서술형 리뷰를 반드시 작성한다. 텍스트 답변의 기술적 정확성 리뷰를 반복하지 말고 말로 전달한 방식에 한정한다.

- **평가 방식 및 신뢰도:** 직접 음향 검토 여부, 사용한 분석 자료, 화자 분리 여부와 제한을 밝힌다.
- **전달 강점:** 청자가 이해하기 쉬웠거나 질문 흐름에 맞춰 설명한 구체적인 발화 근거를 적는다.
- **개선점과 연습 제안:** 전달 구조·질문 대응 등 확인된 개선 대상을 적고, 다음 면접에서 시도할 구체적인 행동을 제안한다.
- **근거:** 질문 번호와 짧은 인용 또는 녹음 시각을 붙인다. 직접 청취하지 않았다면 음량·억양·실제 발음 명료도 등 확인할 수 없는 음향 특성을 단정하지 않는다.
- **종합 리뷰:** 강점과 개선점을 연결해 짧게 요약한다. 근거가 부족한 항목은 평가 불가로 표시하고, 리뷰 전체의 신뢰도 한계를 명시한다.

음성 자료가 없으면 `음성 자료 미제공 — 음성 점수 및 리뷰 미작성`이라고 기록한다.

## 4. 피드백

### 잘한 답변

질문 번호와 근거를 붙여 최대 3개 작성한다.

### 우선 보완할 답변

질문 번호별로 `빠진 근거/오류 → 왜 중요한지 → 개선 행동 → 다음에 확인할 성공 기준`을 적는다.

### 기술적으로 정확히 짚을 부분

실제 오개념이나 모순이 있을 때만 쓴다. 후보자의 주장과 정확한 설명을 구분한다. 해당 내용이 없으면 `확인된 중대 오개념 없음`으로 쓴다.

## 5. 총평

이 면접에서 실제로 답한 질문에 대한 강점과 가장 중요한 공백을 요약한다. 평가 범위가 좁다면 그 한계를 명시한다. 점수를 전체 역량이나 채용 합격/불합격 판정으로 확대하지 않는다.

## 6. 다음 연습 계획

최대 3개. 이번에 낮은 점수를 받은 질문과 평가하지 못한 핵심 직무 영역을 구분해 제안한다. 각 목표에 연습 방법과 성공 기준을 붙인다.

## 7. 다음 회차 추천 질문

참가자의 기록이 있으면 3~5개를 제안한다. 각 질문에 대상 역량 태그, 기준이 된 이전 질문/답변, 추천 이유, 난이도, 후속 질문, 좋은 답변에서 확인할 신호를 붙인다. 개인별 파일은 `records/participants/<participant_id>/question-recommendations/`에 저장한다.

## 8. 이전 면접 대비 성장

- 이전 기록: 있음 / 없음
- 비교 가능성: 높음 / 부분 / 낮음 / 비교 불가
- 비교한 질문/역량 태그 및 변화:
- 확인된 성장:
- 아직 평가하지 못한 영역:
- 비교 한계:

질문 범위나 난이도가 다르면 총점 증감을 성장으로 단정하지 않는다. 기록이 없으면 `이전 기록 없음 — 이번 세션만 평가했으며 성장 추세는 판단할 수 없음`으로 쓴다. 비교에는 동일 참가자 ID의 기록만 사용한다.

이전 세션의 총점이 `/100` 텍스트 점수만 포함하는 구버전이면 새 텍스트·음성 평균 총점과 직접 비교하지 않는다. 과거 음성 녹음이 보존되어 있으면 새 루브릭으로 별도 재평가한 뒤 비교 가능성을 검토한다.
